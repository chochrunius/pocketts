# AlfredTS 1.7.0

Based on the official PocketTS 1.7.0 tag. Android version code **9**.
Application ID **io.github.chochrunius.alfredts**.

## What changed

- Favourites can be grouped, collapsed, renamed and reordered by dragging.
  Each favourite can select a channel and store its encrypted password.
  AlfredTS can find a previously joined channel by ID after it is moved or renamed.
- The connection screen includes six official TeamSpeak community servers.
  The blue **Connect** button is back above the nickname and server address,
  and connection errors stay visible below the header.
- Playback settings offer loudspeaker or earpiece output and a connected-headphones
  preference. Earpiece mode uses the proximity sensor where supported.
- PocketTS improvements include clearer settings, steadier dialogs when typing and
  camera controls for TeamSpeak 6 streams, including zoom, focus and lens selection.
- AlfredTS keeps its Czech translation, branding, GitHub update source, Ludmila
  Chochrun.eu default on first use, and scrolling to your own row after connecting.
  Existing favourites, identity, credentials and channel history carry forward.
  Explicit channel links and the new favourite channel coexist with the existing
  default channel and last-channel settings.

## Installation

Download **AlfredTS-1.7.0.apk** for Android 10 or later on ARM64 or ARM32.
Production AlfredTS 1.6.1 uses the same application ID and signing identity.
Install over the existing app if you want to keep its data. The separately
installed test build uses the .shrunk package.

The user manually accepted the side-by-side test build, including the Connect
button position. The production-signed APK was not used for that phone test.
