# AlfredTS 1.6.1

Version name: **1.6.1**; Android version code: **8**.
Application ID: **io.github.chochrunius.alfredts**.

## Changes

- On first initialization, add **Ludmila Chochrun.eu**, address `chochrun.eu`, if no
  equivalent favourite exists. It remembers the last channel and does not connect
  automatically. Its nickname, password and default channel are empty; no custom
  file-transfer port is set. An empty favourite nickname uses the app nickname.
- Fresh installs initialize the connection nickname to `AlfredTS_VaseJmeno` and
  address to `chochrun.eu`, with an empty password and password memory off.
  Last-channel memory is enabled. “In favourites” reflects the saved favourite.
- Existing installs fill only blank nickname/address values. Existing favourites
  (including auto-connect choices), explicit channel preferences, last-channel
  history, identity and credentials are preserved. A persistent marker prevents
  recreating deleted defaults or restoring fields cleared after initialization.
  Malformed favourite storage is left intact; initialization waits for its repair.
- Release certificate verification accepts the standard and V2/V3 apksigner
  formats, requires at least one valid SHA-256 digest and rejects any signer
  differing from the configured trusted certificate.

## Installation and compatibility

Download **AlfredTS-1.6.1.apk** and install it over production AlfredTS 1.6.0,
without uninstalling first. The application ID remains
`io.github.chochrunius.alfredts` and the production signing certificate is unchanged.
Android 10 or newer; ARM64 (`arm64-v8a`) and ARM32 (`armeabi-v7a`).
Debug/shrunk builds and PocketTS using a different application ID remain separate apps.

The user manually tested and accepted both an update from production 1.6.0 and a
fresh installation on a real Android smartphone, including the default server,
favourites, nickname, channel preferences and existing functionality.
