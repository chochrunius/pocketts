# AlfredTS 1.6.0

First official release of AlfredTS, an independently maintained Android fork of
[PocketTS](https://github.com/KorppuJauho/pocketts), published by
[chochrunius/pocketts](https://github.com/chochrunius/pocketts).
Version name: **1.6.0**; Android version code: **7**.

## Changes in this fork

- **Czech localization:** Czech interface text, including plural forms and formatted
  messages; Czech is available in the app's language picker.
- **Channel preferences:** set a default channel for each server/favourite and optionally
  remember the last joined channel. Explicit channel links select the initial channel;
  reconnecting can return to the remembered channel when enabled.
- **Channel scrolling:** initial positioning finds your channel and user row by ID,
  including on large or changing channel trees. The initial animation can be disabled
  in Advanced settings, and manually scrolling cancels the initial positioning.
- **Connection errors:** errors appear below the application header on the connection
  screen, leaving the heading visible.
- **AlfredTS branding:** application name, header artwork, launcher/adaptive/monochrome
  icons and notification icon, plus updated application references in translations.
- **Independent updates:** the GitHub release build checks published releases of
  `chochrunius/pocketts`, rather than the upstream PocketTS repository.

## Included upstream work since PocketTS 1.5.0

- Optional on-device debug log with privacy filtering and explicit sharing.
- Optional RNNoise microphone noise removal.
- Push-to-talk/whisper controls and volume adjustment while viewing a full-screen stream.

These features come from PocketTS; they are not original AlfredTS fork changes.

## Install and compatibility

Download **AlfredTS-1.6.0.apk** and open it on an Android 10 or newer phone.
Supported ABIs: ARM64 (`arm64-v8a`) and ARM32 (`armeabi-v7a`). No Google Play upload
is part of this release.

The application ID is **`io.github.chochrunius.alfredts`**. This is a separate
installation from PocketTS and earlier AlfredTS test builds using the upstream ID.
It does **not** update those installations or automatically import their TeamSpeak
identity, server permissions, favourites, saved passwords, settings or chat history.
Keep the old application and its data until you have arranged any identity transfer
or new server permissions. Both applications can coexist, and Android may ask which
one should open a TeamSpeak link. Microphone, camera, notification and overlay access
must be granted separately as needed.

Future AlfredTS updates require this application ID and the same release signing
identity. Debug and shrunk test builds are separate installations as well.
